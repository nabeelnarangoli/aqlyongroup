# Aqlyon Group of Companies — website

Static, single-page website for Aqlyon Group of Companies and its companies:

- Aqlyon Marketing Management (Dubai, UAE) — www.aqlyondm.com
- Aqlyon Brand Management (Kerala, India) — www.aqlyondm.com
- Aqlyon Career Discovery Centre (Kerala, India) — aqlyonacademy.com
- Codewyn Technologies (Kerala, India)

## Structure

- `index.html` — the whole site (HTML + CSS, no build step)
- `assets/logos/` — company logos (`*-light.png` versions are for dark backgrounds)

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

Works on any static host (Netlify, GitHub Pages, Vercel). No build command; publish directory is the repository root.
